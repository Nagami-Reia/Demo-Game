# 人物盟约属性：标签依据与风险审计草案

日期：2026-11-06。只作设计审查，未修改人物标签、游戏规则或UI。依据本项目已读官方人物资料与[卫戍协议研究笔记](stronghold_protocol_study_20261105.md)，未重新联网核验所有现职。下文“盟约”都是拟议的游戏属性，不是现实组织授予的称号或派系归属。

## 一、标签和什么有关

盟约描述一个人能进入哪种工作链：如何准备、与谁协作、能把什么积累转成哪种成果。它与党籍、优势领域、现实职务和公开组合分别记录：

|已有维度|回答的问题|盟约补充的问题|
|---|---|---|
|优势领域与六项属性|这个人在什么议题、什么行动上适用|他在体系中产生、放大或消耗哪类准备资源|
|政府/委员会职责|他目前承担什么权限与职责|这项职责能否构成可重复的成长触发；没有权限也可能承担辅助环节|
|党籍与党团关系|合作成本、纪律与组织归属|跨党专业成员是否能承担相同的体系环节|
|Merz＋Frei等具名组合|特定两人公开合作如何发挥|同类职能是否存在其他可用的替代者|
|真实党内派系/组织平台|有来源的现实成员关系|仅在有直接资料时为标签提供背景，不能包办全部盟约分类|

建议初版每人只分配一个核心盟约、至多一个辅助盟约。不能为了凑齐体系，把资料丰富的人贴满所有盟约；也不能把资料缺失解释为“此人没有能力”。标签设计应覆盖低阶和多个党派，不能让高阶或执政党独占生产、放大、兑现三个环节。

## 二、采用什么证据

每个标签至少保留一条“事实—设计解释”的记录：人物ID、事实摘要、具体来源、资料日期、拟议标签、在成长链中的角色、当前/历史性质、是否还需核查。事实与系数分开。

证据的优先次序：

1. 有具体职责的持续工作，如预算工作组负责人、联邦与州协商职责、卫生科研背景。
2. 已有原始资料记录的长期专业工作或组织协调经历。历史经验可以支撑人物属性，但不得恢复已卸任机关权限。
3. 官方列出的平台成员关系，可以证明“属于该平台”，不能单独证明此人能控制平台、筹集大量资源或拥有某种私人关系。
4. 一次演讲、一次共同合影、学历或职业名称，通常只能作为待核查线索。

必须避免的捷径：律师不自动获得强力“法治盟约”；经济学位不自动获得“产业游说”；部长不同时获得所有研究、组织和执行标签；有名不等于有可核查的传媒动员能力。党团领导也不等于擅长一切专业领域。

## 四、三人、八轮的激活与增长约束

建议用两名不同ID的出战人物启动一条核心路线，三名同核心取得强化而非第二套独立常驻总倍率。辅助标签通常一人可触发，但只改变一种窄条件。招到一人只是在构筑中保留机会，不能等同于立即启动持续生产。

只要当前仍为三人出战，不宜照搬需要六人出场的阈值。若允许收藏人数解锁，则必须明确那是“后备准备资格”，不得同时生产出战层数、提供战斗倍率和领取经济收入。

初版每条盟约建议每轮最多增长一次；实际八轮最多八次，里程碑可先测试第2/4/6次，而不是设第10/20层、最终只能靠刷动作达到。若某路线需要更多细粒度层数，仍应按阶段上限固定预算，不能让同一动作的监听器数量决定成长速度。

## 五、平衡风险与建议边界

|风险|容易产生的错误|建议边界|
|---|---|---|
|跨阵营招募|同一盟约抹掉所有党际分歧，AfD卡加入专业路线后免除防火墙|共享专业路线允许跨党启动，但不替代开局谈判、政策相容性、组织归属或防火墙规则|
|同党三人叠加|同党组织+党团指挥+党派盟约再重复三次“全体更强”|盟约增加准备、转化或一次有条件行动；现有组织倍率继续独立，不再复制同类固定百分比|
|领袖否认|抢走一张牌同时偷走党团、盟约层数、全部经济生产|只否认该人物之后的出战资格与职务作用；已有团队成长不转赠给夺卡方，未使用准备也不被直接掠夺|
|板凳刷层|买到人物后留在收藏里，持续取得行动层数与回合收入|成长由实际出战、相关议题和有贡献的行为触发；持有本身最多保留标签，不产生层数|
|重复买卖/退款|特选两张选一退一，也被当成两次正式招募或出售触发|正式结算归属并留存后才进入体系；退款、未保留牌、回放、重渲染不触发成长|
|失去人物|全队成长瞬间清零，导致抢卡强制终结；或人物被抢后把整队成长带给对方|已形成的团队准备归原方，失去人物只影响后续生产与当前激活；消耗需要符合条件的替代成员，防止无成员继续全力兑现|
|自我循环|经济获得金币→加层→再获金币；盟约加分→成功→再加分无限递归|触发源限定为原始行动事件；结算产生的派生奖励不再作为新生产事件；金币收益不按持有余额计算，不引入利息|
|滚雪球|赢一轮就加层，强者持续更强|成长跟有效工作行为相连，不与本轮胜利完全绑定；可以输掉议题但留下准备，形成转型机会|
|临终高阶卡|第6轮T5一到就取代前五轮培养，或太晚来完全无用|高阶可提高兑现效率但不能补造过去层数；至少有一个低准备下的有限基础用途|
|无核心可玩|某职业只有一张领袖卡，未抽到即全局报废|核心路线至少有多个低中阶生产者和两个不同兑现选择，且应分布于多个党派；最终人数要对全卡池抽样再确认|
|多标签取巧|同一人物同时算两名、轻松凑多个核心|人数按不同人物ID计；同一人每条路线只计一次；核心+辅助数有上限|
|得分双领|专业、机构、组合已加到行动强度，盟约又按同名效果直接发一次成果|新效果进入现有贡献账本。除非是明确不同的消费事件，不再给同一成功重复成果分|

这里对“失去人物”的讨论是为未来抢卡/转移规则预留，不能把“当前竞拍抢先拿到一张共享牌”擅自升级为已经实现的强制转移玩法。

## 六、事件次序与可审查性

建议顺序为：冻结出战阵容与激活路线 → 消耗本轮已拥有准备 → 正常行动/组织/计分 → 收集可增长的原始事件 → 每条路线受上限地结算成长 → 下一轮可使用。这样不会把本次由盟约强化的成功再用来即时递归强化自己。

每次触发记录：队伍、盟约ID、原始事件ID、人物ID、议题权重、层数/准备变化、消费原因、实际贡献。用“回合+阶段+人物+行动序号”防重复，不能依靠界面按钮是否重复点击来判断。

为让电脑判断构筑，设计表应提供公开的启动成员数、生产/消费条件、剩余回合价值、可替代者与路线切换损失。电脑竞价时不读取未公布议题；部署时才使用已公布的多领域权重。不能只给T5贴盟约后期待旧的面板估价自行理解成长链。

## 七、建议先测的三组对照

1. Middelberg/Haase/Güntzler财政准备线：缺一张时能否以另一中阶成员启动，且相对升中心/存竞拍金有真实取舍。
2. Krings＋一名其他党法律工作者的程序线：专业可以协作，但不同政策目标、首次谈判和跨阵营成本仍然存在。
3. Streeck＋专业证据生产者＋落实者：输掉前期议题仍能形成有限准备，第6轮高阶到来可以更好兑现，但不应瞬间获得未培养时同样的完整收益。

第二、三组的另一党成员在正式分配标签前还需逐人补核来源；本草案不据职称批量猜测。上述均为测试场景建议，未声称已模拟或得出胜率。
