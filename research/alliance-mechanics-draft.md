# 人物盟约机制草案 v0.1

日期：2026-11-06。只供设计讨论，未修改游戏、人物标签、数值或UI。本稿基于 `stronghold_protocol_study_20261105.md` 的既有研究及当前计分、同党组织、政府/委员会职责机制。下文名称、分类、阈值和效果全部是本游戏设计假设，不是《卫戍协议》官方规则，也不是对真实政治人物能力、私人关系或道德品质的测量。

## 要学的结构

学习“启动者—生产者—放大器—兑现者”和缺核心时的转型，不直接复制某版的3/6人阈值、清空金币或干员数值。我们只有三人出战、八回合，还保留现金且没有利息；需要更早启动、更少层数、更明确上限。

盟约表示一个人具有的职业背景、公共工作经历或可核查的政治实践路径。例如同一人可以同时具有财政网络、地方联络、法学训练；标签可以跨党派，也不意味着属于秘密派系或会无条件跟从别人。党籍、优势领域、现任机关职务、实名人物组合与盟约分开保存。

## 推荐的公共规则

- 每人允许1–2个核心盟约、0–2个辅助盟约；没有资料时宁可少给，不能为凑构筑贴满标签。相同人物在同一盟约只算1人，不能因两个职务算2人。
- 两名不同人物同核心即可启动，三名同核心提供更高效的成长或兑现途径。**单张卡可以具有盟约，但不独自启动完整体系。** T1/T2要有生产者与过渡者，T3/T4提供放大或兑现，T5通常只是可选的高效环节。
- 每队每轮最多启用两条核心盟约，称为主盟约与副盟约。作为后续交互设想，可在已有部署阶段记住选择、给出默认推荐，不再弹确认。若不愿增加任何选择控件，首版可暂只做一条核心，按人数和公开议题相关度推荐，部署前可替换。
- 每条核心资源上限9；每轮全队最多产出6点、单核心最多3点。资源属于玩家的组织存量，不是个人卡上可被直接继承的金币。行动成功且贡献为正才产出；同一人物对同一核心每轮最多触发一次，避免三个阶段重复刷层。
- 两人启动提供基本兑现，三人启动提高生产上限或降低一次兑现成本；不再额外给一个“同党三人+组织”式固定强度。不同核心拥有不同触发与资源用途，不能只是八种颜色的同一个攻击加成。
- 兑现方式在部署时预先声明，自动战斗按时点使用；不能看完失败再决定消费换结果。层数不足就不消费、不产生负余额。
- 盟约效果仍经过行动、组织和五项计分；不绕过计分系统直接送1–3分。新增盟约总作用设置预算：单次行动从所有盟约获得的额外强度合计暂不超过0.8，整轮有源净贡献另单独记录。该阈值须通过对照测试调整。
- 回合结束才结算新增资源，不能用本次兑现额外产生的资源反复兑现；任何盟约效果都不再次触发自身或另一个“产出效果”。真实招募才可触发招募类生产，流拍、退款、二选一丢弃、读档、重渲染不算。

**核心与副核心共享限制很重要。** 两人各带两个标签能启动两条路线，但不能因此多开一套独立无限经济；三人专注同核心则更快达到高效兑现。这样重叠标签提供转型，而不形成“带最多标签的人永远最强”。

## 八种核心候选

以下资源名用于便于理解，底层可以统一为各盟约独立计数器，不要求引入八套可转账货币。首轮原型建议只做文末四种，其余先保留设定。

| 核心盟约 | 人物标签的证据方向 | 如何成长 | 两人启动时如何兑现 | 三人深化与代价 |
|---|---|---|---|---|
| 财政网络 | 财政、税务、预算专业分工及相关职业经历 | 经济领域权重≥25%，本盟约成员成功完成专业修正，各+1“筹措”，每轮最多3 | 部署前消耗3点，获得下一次自己支付公共升级时1€折扣，最低价仍2€；每轮至多1张、不可转现金 | 三人同核心时当轮第一次有效触发额外+1，仍受核心3/全队6上限；不用立即战斗加成换未来购买力，末轮不得把过期折扣兑成资金 |
| 立法工作坊 | 法律职业、立法写作、专业审议分工 | 成功专业修正且议题为法案/预算时+1“文本”，每人每轮一次 | 部署前消耗3点，使本轮第一次成功修正额外推动一次有限政策文本调整，朝本方目标最多0.08；仍须经过程序，不直接宣布通过 | 三人时成本降为2点；同一政策文本的盟约调整合计封顶0.10，不能反复逼近目标刷政策分；质询可转为有限回应质量而非推进不存在的法案 |
| 公共服务网 | 卫生、教育、社会服务、相关公共行政经历 | 社会领域权重≥25%时的成功专业贡献+1“服务准备” | 消耗2点，保护本轮一名已声明人物，抵消一次外部社会事件带来的部分人物状态损耗（暂定能量/压力变化的25%）；不保护政策失败 | 三人时保护两人，但总抵消量不翻倍；与韧性恢复取统一上限，不能消除防火墙代价或组织红线 |
| 地方联络网 | 市长/地方行政、选区协调或有来源的地方组织工作 | 首次成功协调+1“联络”；当轮实际留用一名新地方联络成员可再+1，招募只在结算后计入 | 消耗3点，为一名跨党人物的开局协商提供一次有限助力（暂定该次谈判强度+0.4） | 三人时失败可保留其中1点资源；只能提高沟通能力，不能删除首阶段谈判，也不能改党籍或绕过真实政治分歧 |
| 产业创新圈 | 企业/产业、工程技术、科研和产业政策经历 | 数字或经济权重合计≥40%，成功专业修正+1“项目”；同队相关专家与执行者均贡献时额外+1 | 消耗3点，提高本轮一次相关专业修正的落实强度（暂定+0.6），效果由成功行动转成贡献 | 三人时可分配为两次+0.3，而不是加倍；相关部长/委员会的既有加成不再复制一份，必须有不同人物完成研究与执行 |
| 国际协商桌 | 外交、欧洲事务、国际谈判/议会合作的公开经历 | 外交领域权重≥25%，成功的跨党协商+1“协商准备”；同党国际合作专家的专业修正也可+1，避免只有跨党才可玩 | 消耗3点，为一次外交相关协商+0.5强度，并提高该次成功协商对政策文本的实际权重；没有成功则不取得文本效果 | 三人时可用专业修正替代其中一次谈判作为兑现触发；外交准备不能用于普通内政议题，也不能影响现实意义上的外国行为 |
| 议会攻防组 | 议会审议、监督、问询、公开程序工作经验；不凭“善于攻击”人格判断 | 成功监督+1“问题线索”；执政方成功回应/相关专业修正也可积累，双方可用 | 消耗3点，对本轮预先声明的一名对方人物施加一次质询压力，暂定其下一次非谈判行动强度−0.3；被针对方若先完成有效专业回应则抵消 | 三人时未兑现的压力保留1点资源；压力每人每轮最多一次，不再连扣民调、组织度和最终分，防止三重惩罚 |
| 跨界协调圈 | 明确的跨领域或跨机构履历、正式协商工作；不由“曾经换党”自动认定 | 成功跨党谈判，或不同领域人物共同完成相关修正，各+1“协作准备”，每人每轮最多一次 | 消耗3点，让本轮一个已经存在且有来源的实名组合获得一次25%的额外兑现；没有实名组合时，可改为两名不同人物的下一次相关协同各+0.15 | 三人时可在两种兑现方式中选择；不凭盟约标签虚构私人关系，不能额外复制整个党团指挥倍率 |

### 避免核心重复

“财政网络”购买未来经济，“立法工作坊”改变政策文本，“公共服务网”保护人物状态，“地方联络网”帮助开局谈判，“产业创新圈”提高专业执行，“国际协商桌”把外交协商转成政策影响，“议会攻防组”产生可回应的对抗压力，“跨界协调圈”放大已有协同。现有领域决定**这轮能否发挥专业**；盟约决定**过去几轮怎样形成下一步能力**，二者各有作用。

## 五种辅助候选

辅助是个人属性修饰，不要求凑两人，也不另开一套层数。每人每轮最多启用一条辅助触发；全队辅助每轮最多贡献2点核心资源，计入全队6点总额。

| 辅助盟约 | 证据方向 | 候选作用 | 限制 |
|---|---|---|---|
| 法学训练 | 可核实法律教育或职业 | 当本人本轮首次成功完成相关法案修正时，给当前启用的立法工作坊额外1点文本；若没有启用，不凭空创建资源池 | 不是现有专业背景+0.45再叠一次；只改成长路径 |
| 财经训练 | 可核实财会、经济、税务职业/训练 | 本人出战且本方当轮实际支付过升级或留用招募时，在本人首次相关有效行动后给财政网络额外1点筹措 | 不能因返币/重复竞价计数，也不能依据人设称其更廉洁或节俭 |
| 技术训练 | 工程、科研、信息技术等训练/职业 | 本人本轮首次匹配数字/产业相关议题的有效专业行动，为产业创新圈额外1点项目 | 不因为有博士头衔就加；必须有相关训练依据，且不附送额外专业域 |
| 公共传播 | 新闻、公共传播职业，或可核实的公开信息组织职责 | 可以在部署前选择消费当前核心1点资源，让本人的一次有效回应减轻0.1点原始常规负面民调冲击 | 不影响防火墙、严重丑闻或公开红线；不把媒体曝光量当能力测量 |
| 执行经验 | 有明确职责范围的行政/项目落实经验 | 本人有效行动能作为“产业创新圈”研究—执行链的执行端，或为公共服务网的一次状态保护增加小幅效率（两者择一） | 资格/触发修饰，不复制现任部长+1.2；旧行政履历不恢复现任权力 |

辅助不是五项永久面板加分。现有专业背景、政府和委员会加成继续只算一次；同一条事实可以解释标签的资格，但不能用“法学背景”同时凭空获得多笔同类行动加成。

## 四种可玩的构筑示例

1. **财政—产业：** 两名财政成员积累未来折扣，一名产业/技术成员撑当轮；第3轮特选前要判断是升级经济还是争夺成长兑现者。没拿到高阶核心，普通专家仍可把筹措用于升级，不是空等某张领袖卡。
2. **立法—地方：** 地方联络提高一名外党专家的首轮谈判，之后专家产生文本，再用文本推动接近本方的修订；政治分歧仍影响谈判与最终政策目标，不能把三名SPD变成CDU。
3. **公共服务—攻防：** 面对持续两三轮的社会事件，保住人物状态并用有效回应积累线索；下一轮才有资源施压。落败不必直接崩盘，但没有“因为输了就白拿层数”的自动补偿。
4. **国际—跨界：** 外交与经济并重的议题可用跨党国际专家开协商，再放大已有有源组合。缺少高阶外交人物时，两个合格的中低阶成员仍能以较慢速度启动；若后续议题不匹配，可转到地方或立法，不必须继续追外交牌。

这些是构筑示例，不是已完成的逐人盟约分配；具体人物归属必须另有来源审查。一个人的经济优势领域不能自动证明其属于财政网络，党团职位也不能自动证明其拥有所有组织类盟约。

## 与抢卡、T5和八轮时长的关系

- 第3/6轮特选仍是原T5叠一个特选行动效果。盟约标签属于人物，普通版本与特选版本保持一致；特选可以更高效地完成某个环节，但不额外算一名成员或送一个完整盟约。
- 目前竞拍争夺的是公共池中尚未持有的人物。买到对手党籍的关键人物，可以破坏其潜在构筑或维持现有组织否认，但不会自动拿走对手已存的盟约资源，也不会把对手整条盟约切成己方所有。
- 三人队中一名具有两条核心属性的成员，是转型的桥梁；被对方拍走时，另一名普通生产者仍应能替代。若先用40–60张试玩子池，每条核心至少安排6–8张可用候选，覆盖至少两个党派，并保证至少三名T1–T3。这个最低量不能直接用于全630人池；全池版本要按实际分级抽卡概率测量，目标是在24次常规展示里，主流核心通常有3–5名不同候选可见，不能只靠全库里“存在”某张牌。达不到就先缩小可见子池或扩充有源成员，而不是默默越级发核心。
- 只有八轮，不能要求第6轮以后才首次启动；两人体系应在第2–3轮可形成，并在第3–4轮出现首次可观察兑现。此时间窗是原型验收目标，不是承诺抽牌概率。
- 不给闲置金币生利息、不因资源层数直接加永久收入。经济盟约需有行动和机会成本；第一轮购买一张卡不能立刻回本再买下一张，防止循环套利。

## 最小原型与审查项

为控制组合复杂度，建议首轮人物只赋1个核心＋最多1个辅助（同一个人仍具有多种盟约属性），数据结构保留以后1–2核心/0–2辅助的扩展能力。不要第一轮就把所有候选都用双核心赋满。

建议首轮只落地四条核心：财政网络、立法工作坊、公共服务网、议会攻防组；配法学训练、财经训练、执行经验三条辅助。四者分别验证未来经济、政策文本、人物状态与可回应对抗，机制差异大。其余四条核心与两条辅助保留为后续扩展；不需要一次塞满13套新标签。

原型应做成数据表，不写进某个人名的分支：`allianceId / core-or-aux / publicBasis / source / trigger / perPersonCap / perRoundCap / spendTiming / consumes / effect / excludedEvents`。每个触发有稳定事件ID，方便读档防重、对局导出与独立审计。

验收至少包含：同一行动多阶段不刷层；普通/特选不双计身份；二选一退款与弃卡不刷资源；背景/机关/同党与盟约不重复奖励同一效果；已有资源不因跨党买卡转账；来源不足不乱贴标签；AI竞拍只看公开卡池与本方库存，不偷看未公布议题；看不到唯一核心卡时仍有替代路线。平衡先比较同种子、同公共报价序列下的有效成长和兑现，不先宣传某套胜率最高。

**首要待确定事项：** 是否接受“主/副核心最多两条”的控制方式；经济资源是只做升级折扣，还是允许有限下一轮收入。推荐先采用最多两条核心与只做升级折扣，避免盟约刚加入就把现有高余额问题放大。
