# Koalitionsprotokoll — 本地可玩版

直接用 Chrome、Edge、Firefox 或 Safari 打开 **index.html**。无需安装，无需服务器，断网可玩。源文件改动后运行 `python3 build.py` 重新生成入口；Python仅用于打包，游玩时不需要。未来可把整个文件夹上传GitHub Pages，入口仍是index.html，本次未发布。

## 操作

1. 玩家身份目前锁定执政党，选择CDU、CSU或SPD。电脑从AfD、Grüne、Linke选择反对党。
2. 每轮刷新12€基础预算加永久奖励；第4与第7轮基础预算各+1€，余款保留且无利息。公共中心全场每轮只能升级一次，付款者从下轮获得收入。双方交替优先升级。
3. 三张公共卡逐张竞拍。选择出价或放弃，电脑自动计算回应；下一张及议题在规则时点前不生成。跨党购买遵守党际招募禁令。同人全局唯一。
4. 竞拍结束后公布议题，从自己的库中选择1–5人，锁定后选择谈判方案再自动模拟；特殊盟约可能在行动中暂停，让玩家选择接手或履约。
5. 查看事件、人物行动和展开解释。政府争取阶段推进、专业贡献；反对党争取监督和协商影响。分别计分，未推进不等于政府必定零分。质询单独显示监督/回应结果，不称作立法通过。
6. 八轮累计成果决定胜负；可随时切换中/英/德、浅色/深色。每次操作后自动存入本浏览器；初始页可继续上局。对局历史支持导出JSON。

- `web/js/sandbox.js`：箱庭状态反馈的轻量JavaScript迁移，保留压力/精力/信心、定向关系、防重和跨轮恢复。

- `data/agendas.json`、`events.json`：30个真实议题背景与9个假设事件模板；考据和程序边界见`sources.md`。

- `tests`：电脑策略、完整对局规则、确定性重放和本机浏览器检查。

## 当前范围与边界

这是可玩的规则原型，不是完整德国议会模拟。议员采用2025年政府成立阶段名单快照，不能当成2026实时名录。资料来源在上述文件中；属性与目标权重是游戏设计，不能当作真实人物能力评价。

六级招募已具备，当前真实卡填充T1–T5，T6保留特殊卡。卡池采用2025-03-25成立快照，不代表当前实时名单；身份数据由官方完整名录导入，新增卡属性为可复现游戏配置，非真实能力考据。因部分等级可能耗尽，某档耗尽时在可用卡内抽样，全部耗尽时跳过该卡位；没有三合一。经济、评分与各党差异仍需要试玩调优。

外部环境首版采用9类可触发事件和按领域继承的环境压力，结合人物状态与关系产生反馈。没有把箱庭全部LivingWorld、机构日历、宏观经济及司法程序移植到浏览器；原始代码作为参考，当前执行的是明确标注的轻量游戏适配。事件是架空触发，不是宣称现实出现事故。对战结果只代表游戏中的阶段成果，不是现实法律生效或政治预测。

电脑看公开阵容与预算，不读取未来牌、议题或意外事件；纯客户端程序不能阻止使用开发者工具的玩家检查或篡改。后续若做联网对抗才需要权威后端，GitHub Pages本身不提供该能力。

存档为同版本浏览器本地存储，不承诺跨版本迁移；清理浏览器数据会丢失。导出是记录导出，尚不支持从JSON导入恢复。

## 社会事件、动态民调与招募经济

选人改为直接切换卡牌选中状态，不重建列表、不重播入场动画。卡牌悬浮也不再移动。仅保留重大阶段过场与成交提示。

每轮融资时公布一项架空社会事件，例如交通罢工、洪灾、住房示威或能源价格缓解，产生领域压力并更新民调；自动辩论仍有阶段内外部事件。环境影响逐轮衰减，民调和人物反馈跨轮保留。民调是局内模拟，初值为游戏设定，不是现实调查或联网实时数据。

社会事件和本轮政策成果均改变支持率。所有党派合计100%，更新处理负数、归零和异常输入，事件ID防重。相对本局初始支持率的下降产生合法性压力：每降低1个百分点，行动强度扣0.18，最多扣0.75；回升时减轻，恢复初值时解除。页面显示各党变动、合法性压力和可折叠变动明细。

经济参照Stronghold-Protocol的固定招募价格与升级降价机制：T1–T6起价为2/3/3/3/4/4€，实际成交仍由竞拍决定；公共中心当前档等待每轮减1€，最低2€，升级后下一档重新计时。保持12€基础预算、每三轮基础增长1€、余款保留且无利息及投资者永久收入；不添加会破坏三卡共享规则的刷新。出处和适配差异见web/js/economy.js。

## 招募概率修复

抽牌现在分两步：按中心等级抽稀有度，再从该稀有度的剩余人物均匀抽取。人物数量不再乘入等级权重。满级且各现有等级未耗尽时，T1–T5实际概率约5.7% / 11.4% / 22.7% / 34.1% / 26.1%；目前没有T6，故将其权重在现有等级内重新归一化。已售完等级也同样剔除并重新归一化，当前概率可在右上角规则面板查看。已公开卡不会因更新重新抽取。

## 党团关联

人物卡会显示与玩家党团的关系，原党籍不会因购买而改变，也不限制跨党招募。相同规则用于电脑招募和阵容估值。

- 同党：行动+0.30，协调另+0.15。
- CDU/CSU：联盟党伙伴行动+0.40；出战阵容同时包含CDU和CSU时，伙伴协调另+0.35。两党的技能与身份仍保留。
- CDU/CSU与SPD：执政联盟伙伴行动+0.20，协调另+0.25，擅长议题的修正另+0.20。
- 跨执政/反对阵营：基础协调成本为-0.35，加个人谈判×0.07；高谈判（阵容最高≥4）可以直接协作并+0.20，否则合作信任不足时第一阶段先谈判并有-0.20协调成本。专业修正+0.30；成功谈判/协调使合作信任+0.30，失败-0.10，范围0–1，跨回合保留。信任≥0.5后不再强制先谈判，信任还提供最多+0.40。这表示议题合作，不是转党或自动服从。
- 不同反对党：没有自动联盟加成；专业监督+0.10。独立协作保持中性。

回放记录关系类别和实际数值，规则面板提供说明。党派结构采用2025政府成立阶段快照；数值和行为是游戏设计，不是对现实政党合作概率的测量。

官方制度背景：https://www.bundesregierung.de/breg-de/aktuelles/koalitionsvertrag-2025-2340970 （2025 CDU/CSU/SPD联盟）；https://www.bundeswahlleiterin.de/service/glossar/f/fraktionsgemeinschaft-cdu-csu.html （CDU/CSU党团共同体）。

## 电脑招募复现与党团纪律

电脑原先并非完全不招募，但边际阵容估值取整和阈值导致其满3人后过度放弃廉价候补。新的auction_decision按公开局势选择补齐阵容、专业缺口、组织协调、轮换、落后追分或最后一张的预算策略，同时仍拒绝无价值替补。不读未来卡牌/议题/事件。升级也会为未成型阵容保留资金。右侧显示电脑人数与最近决策，避免隐藏的人物库被误认为没有招募。

`tests/fixtures/recruitment-comparison.json`保存24个无竞争、无升级的固定公开牌样本：旧算法购122/576张，新算法192/576张，平均最终库6.08→9。此实验隔离了起拍价购买意愿，不是真人对抗胜率证据，不保证电脑必定买下某张牌。

`data/leadership.json`核实了党团/党组织/行政职务，采用不晚于2025-07-01的历史职务配置（包括6月27日SPD主席选举），与3月成立时议员名单分开。没有把所有T4部长视为党团领袖。来源、秘密票/公开票/记名票及自由委任边界详见`data/discipline_sources.md`。

领袖出战时会尝试组织协调，跨党领袖第一阶段先协商；行动成功不代表党团一定接受。接受程度结合职务范围、议题专长、谈判、既有协议、凝聚力与内部张力。接受可带来有限的组织影响和每方每轮最多1点额外成果；相同党团的双主席不重复叠加，CDU/CSU共享Union组织，双方同时争取同党团时效果折半。领袖不授予未部署人物的所有权或真实票数。

谈判失败且涉及高争议/红线可造成有限反弹，并跨轮积累内部张力；谈成也可能只得到有限支持。对局内组织影响每方每轮限于-1.2至+3。自由表决不触发组织动员；秘密选举削弱影响，不推断真实个人票。当前法案、预算和质询不擅自启用秘密票；自由票/红线等参数只在相应议程明确配置时生效。凝聚力初值、概率、数值与副作用是游戏模型假设，不是对现实政治人物的实证测量。

## 本局记录驱动的组织机制修复

用户提供的对局总分27:52。维德尔第6轮买入并出战，该轮成功协商仅给旧版1.36行动力和1额外分；第7、8轮未部署。前两轮玩家1/2人对电脑3人，是早期差距的重要来源。旧版没有扣减被抢领袖一方的组织能力，已修复。原导出未包含初始种子/党派信息，因此不宣称能精确重放原局；新的导出包含初始种子、规则版本、双方党派与完整拥有库。

组织完整度按同一党团已核实的党团/党组织领导权重计算。对手持有的领导权重份额乘0.7作为组织缺口，上限65%削弱；党组织职务权重是党团职务的55%，同一人多职不重复算。出战党团领导提供最多18%指挥增幅；对方原有专家仍保有个人能力，不因买走一位共同主席而全部归零。这是抢卡玩法的战略抽象，并不描述现实议员被强制控制。

相同党团、不同人物的党主席与党团主席同时出战，每名相关人物行动+0.5；部长在当前核实职责领域每次行动+1.2，另与组织领袖搭配可+0.3。初始人物从本党T1/T2可用池随机，保留固定种子可复现。

职务改用offices.json的verified_current，历史任职不会再自动产生当前权限；例如Spahn当前无党团主席加成、游戏层稀有度T3，Frei接党团职务。未核实的现任职务不猜测补齐。**630人仍以2025成立名单为身份底册，不能当作全员2026实时名录**；官职核查覆盖已有高阶卡、官方可验证党团/党派领导和在库部长，详见offices_audit.md。

## 主席团统一中立规则

现任议长及副议长统一作为中立主持角色，排除出战阵容、招募池、电脑估值、党团动员和人物组合；不是只对Julia Klöckner硬编码。核对的现任五人为Klöckner、Lindholz、Ortleb、Nouripour、Ramelow，来源：https://www.bundestag.de/parlament/praesidium/praesidium-196416 。角色数据用offices的presidium，新增此职务会自动适用同一规则。

旧存档已买到的主席团卡保留展示并标中立，不再可部署；尚未成交的旧主席团拍卖在恢复时跳过，不扣资金。政治人物总底册仍630人，但当前可招募625人。历史任期已结束者不因曾任议长永久排除。

法律上不是“议长永远不能辩论”：GO-BT §27(2)规定要作为发言人参与辩论时须交出主持。当前游戏未实现主持权切换，因此采取全体主席团固定中立的简化，而不把此游戏限制冒称绝对法律禁令。来源：https://www.gesetze-im-internet.de/btgo_2025/__27.html 。

## 当前生效规则：持续事件、保留资金与T5配对

T6暂停，未启用技能卡或T6人物。第3轮（真实T4）与第6轮（真实T5）的三次常规竞拍后、议题公布前，公开一对特选人物（优先玩家党派与电脑党派，耗尽时使用各自阵营候补），逐张独立竞价。不同赢家各得其卡；同一方赢两张时，选择保留一张，另一张全额退回成交款并离场。电脑自动作相同选择。特选版属于游戏版本，不改变真实职务。每张都需要先付得起成交款，不允许提前透支尚未退回的资金。

融资为旧余额＋本轮基础预算＋个人永久收入，无利息。电脑会为第3、6轮高阶拍卖和后续回合保留预算，不把普通第三张误当终局清仓。
